# Microsoft Excel Dashboard and Automation Collection
A collection of Microsoft Excel projects including Payroll, Gradebook, Decision Factors, Sales Database, and Car Inventory. Each project demonstrates data management, analysis, and automation using Excel formulas, pivot tables, charts, and dashboards.
# Project Overview
This repository showcases practical Excel applications designed for business, academic, and analytical use. Each project focuses on solving real-world problems using built-in Excel tools from payroll automation to sales tracking and decision analysis.
# Features
### Automated calculations and reporting
### Pivot tables and dynamic charts
### Conditional formatting for data insights
### Data validation and filtering
### Dashboard-based visualization
